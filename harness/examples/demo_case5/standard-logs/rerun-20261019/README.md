# Demo 5: native stdout and stderr from a new rerun

For logs and OpGuard output collected in the same launches, use the
[subsequent paired capture](../../paired-capture-20261019/README.md).

These are complete, separate stdout/stderr captures from two successful
two-GPU runs on 2026-10-19. Each run executes all 20 training steps (0–19).

| Run | stdout | stderr |
| --- | --- | --- |
| Communication overlap enabled | [stdout.log](overlap-on/stdout.log) | [stderr.log](overlap-on/stderr.log) |
| Communication overlap disabled | [stdout.log](overlap-off/stdout.log) | [stderr.log](overlap-off/stderr.log) |

The four files contain 53,922 bytes in total. They are direct process output,
with warnings, configuration dumps and training metrics retained. Nothing was
filtered or reordered. stdout and stderr were redirected separately, so their
combined interleaving cannot be reconstructed.

The historical demo trace's original stdout/stderr and complete launch arguments
were not recovered. **These new logs were not generated by the launches that
produced the published demo trace.** They must not be described as its original
logs or used to assert that its exact tensor differences were reproduced.

The [workload](debug.py) comes from [DeepSpeed issue #5545](https://github.com/deepspeedai/DeepSpeed/issues/5545).
Its AST matches the demo's embedded `debug.py` after removing only the OpGuard
wrappers and trace flush. The two configurations differ only in `overlap_comm`.
Neither run applies the optional `--patch_deepspeed` repair. No artificial delay
or weighted-gradient modification was added. OpGuard instrumentation and CUDA
Stream Sanitizer were absent; mandatory heattrace remained enabled.

The reruns use DeepSpeed 0.14.2, Accelerate 0.29.3, PyTorch 2.9.1+cu130 and two
GB200 GPUs. [bootstrap.py](bootstrap.py) supplies two import compatibility names
removed from modern Torch elastic. NCCL logging is configured as `WARN` before
launch; all emitted output is retained. The launch commands, environment changes,
configuration/source hashes and raw log SHA-256 values are in [manifest.json](manifest.json).

In these runs, the first difference in printed training metrics is step 16:
`grad_norm` is `0.00223425869` with overlap and `0.00197029114` without it.
At step 19, the printed losses are `0.12844944` and `0.12809968` respectively.
These observations compare the native decimal log values; no new OpGuard trace
or full tensor comparison was collected for this upload.
